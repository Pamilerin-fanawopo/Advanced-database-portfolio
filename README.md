# MIT8103 – Advanced Database Systems

## Project Overview

This repository contains my practical portfolio for MIT8103 Advanced Database Systems at Miva Open University.

The project uses a fictional fintech platform called FinTrust. The aim is to design and work with a database that supports customer accounts, deposits, withdrawals, transfers and transaction records.

The same case study will be used across all five portfolios.

## Portfolio Activities

1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Database Exercise
