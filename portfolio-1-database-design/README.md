Portfolio 1: Database Design and Modelling

Case Study: FinTrust Digital Financial Services Platform

This portfolio covers the design and implementation of a relational database for FinTrust, a fictional fintech platform.

The database is designed to manage customer information, financial accounts, transactions and records of important activities.

# Tools Used

- MySQL 8.0
- MySQL Workbench
- Git and GitHub

# Work Completed

- Created the FinTrust database.
- Created six related tables.
- Defined primary keys and foreign keys.
- Added sample customer, account and transaction records.
- Created an Entity Relationship Diagram (ERD).
- Saved the database model.
